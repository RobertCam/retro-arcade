# Effects Assets

Shared visual effects and particle sprites.

## Particles
- `particle-star.png` - Star-shaped particle (8x8px to 16x16px)
- `particle-circle.png` - Circle particle (8x8px to 16x16px)
- `particle-spark.png` - Spark particle (8x8px to 16x16px)
- `particle-smoke.png` - Smoke particle (16x16px to 24x24px)

## Screen Overlays
- `screen-flash-white.png` - White screen flash overlay (800x600px, semi-transparent)
- `screen-flash-red.png` - Red screen flash overlay (800x600px, semi-transparent)
- `screen-flash-blue.png` - Blue screen flash overlay (800x600px, semi-transparent)

## Notes
- Particles can be small, simple shapes
- Screen overlays should be gradients or semi-transparent fills
- All effects should support transparency
