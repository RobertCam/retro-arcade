# Breakout Game Assets

Place your Breakout (Neon Shards) game assets in this directory.

## Required Assets

### Core Game Elements
- `paddle.png` - Player paddle (120x15px base, or 240x30px for 2x)
- `ball.png` - Game ball (16x16px base, or 32x32px for 2x)

### Bricks (by theme)
- `bricks/space-1.png` through `bricks/space-6.png` - Space theme bricks (80x25px base each)
- `bricks/underwater-1.png` through `bricks/underwater-6.png` - Underwater theme bricks
- `bricks/jungle-1.png` through `bricks/jungle-6.png` - Jungle theme bricks
- `bricks/volcano-1.png` through `bricks/volcano-6.png` - Volcano theme bricks
- `bricks/neon-1.png` through `bricks/neon-6.png` - Neon City theme bricks
- `bricks/desert-1.png` through `bricks/desert-6.png` - Desert theme bricks

### Power-Ups
- `powerups/long-paddle.png` - Extended paddle power-up icon (24x24px base)
- `powerups/short-paddle.png` - Shrunk paddle power-up icon
- `powerups/multi-ball.png` - Multi-ball power-up icon
- `powerups/slow-ball.png` - Slow ball power-up icon
- `powerups/extra-life.png` - Extra life power-up icon

### Backgrounds
- `backgrounds/space.png` - Space theme background (800x600px)
- `backgrounds/underwater.png` - Underwater theme background
- `backgrounds/jungle.png` - Jungle theme background
- `backgrounds/volcano.png` - Volcano theme background
- `backgrounds/neon.png` - Neon City theme background
- `backgrounds/desert.png` - Desert theme background

## Optional
- `particles/` - Explosion/particle sprites if needed
