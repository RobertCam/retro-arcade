# Game Assets

This directory contains assets specific to each game. Each game has its own subdirectory.

## Games

- `breakout/` - Neon Shards game assets
- `jezzball/` - Containment Grid game assets
- `micro-racing/` - Hyper Runners game assets
- `rivet-rage/` - Rivet Rage game assets
- `tetris/` - Tetra Stack game assets
- `mouse-pacman/` - Mousetrap game assets
- `minigolf/` - Mini Golf game assets
- `tidehold/` - Tidehold coastal tower defense assets

See each game's README.md for specific asset requirements.
