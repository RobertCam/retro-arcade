# Jezzball Game Assets

Place your Jezzball (Containment Grid) game assets in this directory.

## Required Assets

### Game Elements
- `ball-1.png` through `ball-4.png` - Different colored balls (16x16px base each, or 32x32px for 2x)
- `wall.png` - Wall line texture (variable width, 4px thick, can be tiled)
- `captured.png` - Captured area fill texture (64x64px tiled texture)

### Backgrounds
- `background.png` or `bg-pattern.png` - Background pattern (256x256px tiled texture)

## Notes
- Balls should have distinct colors for visibility
- Wall can be a simple neon line that repeats horizontally
- Captured area texture should be subtle to show filled areas
