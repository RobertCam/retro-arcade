# Tidehold assets

Optional illustrated / GLTF assets for Tidehold. The game ships with procedural Three.js meshes and materials (wet stone, lantern gold, bioluminescent accents).

## Suggested drops

```
assets/games/tidehold/

    whirlpool.glb
  enemies/
    drowned-sailor.glb

    leviathan-spawn.glb
  env/
    kelp.glb
    lantern.glb
```

Concept boards live in `images/tidehold-mocks/` for art direction reference.
