# Working Man Game Assets

Place your Working Man (Rise of the Rivets) game assets in this directory.

## Required Assets

### Characters
- `player-left-idle.png` - Player facing left, idle pose (32x48px base)
- `player-left-walk-1.png` - Player facing left, walk frame 1
- `player-left-walk-2.png` - Player facing left, walk frame 2
- `player-right-idle.png` - Player facing right, idle pose
- `player-right-walk-1.png` - Player facing right, walk frame 1
- `player-right-walk-2.png` - Player facing right, walk frame 2
- `player-jump.png` - Player jumping sprite
- `player-climb.png` - Player climbing ladder sprite

- `oligarch-left-idle.png` - Oligarch facing left, idle (40x56px base)
- `oligarch-left-throw-1.png` - Oligarch throwing trap frame 1
- `oligarch-left-throw-2.png` - Oligarch throwing trap frame 2
- `oligarch-right-idle.png` - Oligarch facing right, idle
- `oligarch-right-throw-1.png` - Oligarch throwing trap frame 1
- `oligarch-right-throw-2.png` - Oligarch throwing trap frame 2

### Platforms & Ladders
- `platform.png` - Platform segment (tileable, 16px height, variable width)
- `platform-left-cap.png` - Left edge cap for platform
- `platform-right-cap.png` - Right edge cap for platform
- `ladder.png` - Ladder segment (16px wide, tileable vertically)

### Power-Ups & Collectibles
- `powerup-shield.png` - Shield power-up (24x24px base)
- `powerup-speed.png` - Speed boost power-up (24x24px base)
- `powerup-life.png` - Extra life power-up (24x24px base)
- `moneybag.png` - Money bag collectible (20x24px base)

### Goals & Hazards
- `goal.png` or `retirement-goal.png` - Retirement goal/trophy (80x60px base)
- `trap-falling.png` - Falling trap object (24x24px)
- `trap-moving.png` - Moving hazard trap (24x24px)

## Notes
- Player should look like a worker character
- Oligarch should be distinct and look like a boss/rich character
- All sprites should be readable at their display size
