# Rivet Rage Game Assets

Place Rivet Rage sprites in this directory. The game falls back to procedural graphics when assets are missing.

## Optional Assets

- `player.png` — Working man top-down (32x32)
- `goon.png` — Chase enemy (28x28)
- `bagger.png` — Ranged enemy (28x28)
- `bruiser.png` — Tank enemy (36x36)
- `drone.png` — Fast enemy (22x22)
- `projectile.png` — Player bolt (8x8)
- `obstacle.png` — Girder pillar tile (48x48)

## Notes

- Keep silhouettes readable at small sizes
- Industrial / factory palette (steel, orange hard hat, navy goons)
