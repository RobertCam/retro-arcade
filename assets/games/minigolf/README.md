# Mini Golf Game Assets

Place your Mini Golf game assets in this directory.

## Required Assets

### Core Elements
- `ball.png` - Golf ball (16x16px base, or 32x32px for 2x)
- `hole.png` - Golf hole/cup (32x32px base, or 64x64px for 2x)

### Course Surfaces (Tiled Textures)
- `grass.png` - Grass texture (256x256px, tiles seamlessly)
- `sand.png` - Sand trap texture (128x128px, tiles seamlessly)
- `water.png` - Water hazard texture (256x256px, tiles seamlessly)

### Obstacles & Course Elements
- `windmill.png` - Windmill obstacle (60x80px base, or 120x160px for 2x)
- `wall.png` - Wall/barrier segment (variable width, 32px height, tileable)
- `ramp.png` - Ramp element (80x40px base, or 160x80px for 2x)
- `bumper.png` - Bumper obstacle (optional, 24x24px)

### UI Elements
- `aim-line.png` - Aim direction line/arrow (variable length, 4px thick)
- `power-meter.png` - Power meter/bar (200x20px)
- `power-meter-fill.png` - Power meter fill overlay (for different power levels)
- `hole-number.png` - Hole number display (80x40px)
- `stroke-counter.png` - Stroke counter display (100x30px)

### Optional Course Decorations
- `tree-1.png` - Course tree variant 1 (optional)
- `tree-2.png` - Course tree variant 2 (optional)
- `flag.png` - Course flag marker (optional)

## Notes
- Ball should look like a golf ball with dimple texture
- Hole should have depth/shadows to look like a cup
- Course textures should tile seamlessly
- All elements should be clearly visible against green grass background
